# Withdraw & Predict Features

## Withdraw

### Goal
I want to be able to track withdrawals from the savings pot, this should affect the balance of the pot and also the scheduling

## Predict

### Goal

I want to show something on screen that shows the 'rate of saving'. So this feature kind of adds on from the scheduling, and the need to save part. It should show how much I have been saving, shown as £ per day based on the value of what is saved. From this, the expected date that I will reach my savings goal should be shown if I continue at this rate
